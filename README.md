# # Enterprise Network Design & High Availability

**Course:** NET461 – Computer Network II  
**Institution:** Yanbu Industrial College  
**Tools:** Cisco Packet Tracer

## Project Overview
Designed and configured a multi-router network topology focused on dynamic routing and gateway redundancy.

## Technologies
- OSPF Routing — Area 23
- HSRP Version 2
- IP Addressing and Routing
- Network Troubleshooting
- Connectivity and Failover Testing

## Key Implementations
- Configured OSPF to exchange routing information between routers.
- Implemented HSRP with active and standby routers for gateway redundancy.
- Configured virtual IP addresses and router priorities.
- Tested connectivity and router failover and recovery.
